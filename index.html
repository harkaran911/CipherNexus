Chi-Square Statistical Test
Chi-Square Analysis
Simplified: A math test that looks for unnatural patterns in image colors to spot hidden data.
Complete: Detects LSB steganography by comparing observed vs. expected frequencies of pixel values. LSB embedding equalizes adjacent color frequencies, which spikes the Chi-Square anomaly metric.
LSB steg leaves a measurable statistical fingerprint
χ² = Σ (observed − expected)² / expected
// χ² ≈ 0 → equalized pairs → LSB modified. High χ² → natural → likely clean.

RS (Regular-Singular) Analysis
RS Analysis
Simplified: Checks if chunks of pixels are unusually "messy" in a way that suggests data was hidden there.
Complete: Classifies pixel groups based on their smoothness. LSB modification disrupts the natural ratio of regular to singular groups, causing positive and negative group counts to converge—a reliable signature of stego content.
Detects LSB modification via pixel group smoothness
Groups classified as Regular (R), Singular (S), or Unusable (U)
// In a clean image: R+ ≠ R- and S+ ≠ S-. After LSB steg: R+ ≈ R- — the telltale signature.

Hash Algorithm Comparison
Digest size, speed, security status, and use cases
Algorithm Digest Block Status Use Case
MD5 128-bit 512-bit ⛔ Broken Legacy checksums only. Collision attacks trivial (< 1 sec).
SHA-1 160-bit 512-bit ⚠ Deprecated Git commits (legacy). Google produced collision in 2017 (SHAttered).

⚡
Hash Attacks & Theory
Birthday attacks, rainbow tables, salting, and cracking tools
Birthday Attack: P(collision) ≈ 1 − e^(−n²/2H)
For n-bit hash: ~2^(n/2) attempts needed for 50% collision probability

SHA-256: ~2¹²⁸ attempts (practically impossible)
MD5 (128-bit): ~2⁶⁴ attempts (feasible with GPUs)
SHA-1 (160-bit): ~2⁸⁰ (broken — Google did it in 2017)

// Rainbow tables pre-compute hash→password mappings.
// Salt = random prefix added to password before hashing → defeats rainbow tables.
// HMAC = keyed hash → proves both integrity AND authenticity.
The Economics of Hash Cracking Notice how attackers use GPUs instead of CPUs for hash cracking (e.g., Hashcat vs John the Ripper). Hash functions involve simple, repetitive math that runs optimally on parallel shader cores. A modern GPU cluster can iterate billions of hashes per second.

HMAC vs Plain Hash
Why you need a key for authentication
Hash: H(message) → digest
HMAC: H(key ⊕ opad ‖ H(key ⊕ ipad ‖ message)) → digest

Hash proves: "data has not changed" (integrity)
HMAC proves: "data has not changed AND came from someone with the key" (integrity + authentication)

// Without a key, an attacker can modify the message AND recompute the hash.
// With HMAC, only someone who knows the secret key can produce a valid tag.
// Used in: JWT tokens, API authentication, TLS record layer, IPsec.

Why is ECB Mode Broken? Electronic Codebook (ECB) encrypts identical plaintext blocks into identical ciphertext blocks. Because it doesn't chain blocks or use an Initialization Vector (IV), structured data (like documents or images) leaves visible structural shadows in the ciphertext. Modern systems default to AES-GCM for both encryption and authentication.

How RSA Works
Mathematical foundation
Key Generation:
n = p × q (modulus — public)
φ(n) = (p-1)(q-1) (Euler totient)
e: 1 < e < φ(n), gcd(e,φ(n)) = 1 (public exponent)
d = e⁻¹ mod φ(n) (private exponent — modular inverse)

Encrypt: C = Mᵉ mod n
Decrypt: M = Cᵈ mod n
Sign: S = Hᵈ mod n (H = hash of message)
Verify: H = Sᵉ mod n (must match original hash)

// Security: factoring n into p,q is computationally infeasible for large n (2048+ bits)

Module 07 — Reference

Theory & Concepts

The academic foundation — steganography, RSA, AES modes, entropy, cold boot attacks.

Steganography

What is Steganography?

Steganography hides the existence of a message — unlike cryptography which hides its content. From Greek: steganos (covered) + graphia (writing). A hidden message raises no suspicion; an encrypted file screams "something secret is here."

Modern digital steganography hides data inside: Images, Audio files, Video frames, Network packet timing, Text whitespace.

Multi-bit LSB

1-bit vs 2-bit vs 3-bit LSB

Standard 1-bit LSB replaces only the rightmost bit of each channel, changing pixel values by ±1 — completely imperceptible. 2-bit replaces the two LSBs (±3 max change), tripling capacity with minor quality loss. 3-bit replaces three LSBs (±7 max change) — noticeable on close inspection but triples capacity again.

1-bit: mask = 0xFE, bits/pixel = 3, max_delta = ±1
2-bit: mask = 0xFC, bits/pixel = 6, max_delta = ±3
3-bit: mask = 0xF8, bits/pixel = 9, max_delta = ±7

// Capacity: (W × H × 3 × depth) / 8 bytes
RSA Cryptography

RSA — Asymmetric Encryption

RSA security relies on the computational difficulty of factoring large semiprime numbers (n = p×q). Encryption uses the public key; decryption requires the private key. The modular inverse relationship between e and d ensures only d can undo what e does — and vice versa for signing.

Public key: (n, e) — share freely
Private key: (n, d) — keep secret

Encrypt: C = Mᵉ mod n
Decrypt: M = Cᵈ mod n

// For 2048-bit RSA: factoring n would take longer than the age of the universe
AES Modes

Why Cipher Mode Matters

AES is a block cipher — it encrypts 128-bit chunks. The mode determines how blocks are chained. ECB encrypts each block independently, leaking patterns. CBC XORs each block with the previous ciphertext. CTR/GCM turn AES into a stream cipher, enabling parallelism and (in GCM) authentication.

The IV (Initialization Vector) randomizes the first block in CBC, ensuring identical plaintexts produce different ciphertexts. Reusing an IV with the same key in CTR/GCM allows full plaintext recovery — one of the most catastrophic possible mistakes.

Shannon Entropy

Entropy & Encrypted Data

H(X) = −Σ P(xᵢ) · log₂ P(xᵢ)

English text: ≈ 4.0 – 4.5 bits/byte
Compressed data: ≈ 7.5 – 7.9 bits/byte
Encrypted data: ≈ 7.95 – 8.0 bits/byte (theoretical max)

Encrypted data is indistinguishable from random noise — maximum Shannon entropy. This is how forensic tools detect encrypted partitions on disk without decryption, and why you can't compress encrypted data.

Cold Boot Attack

RAM Key Persistence

DRAM cells retain data for seconds to minutes after power loss. At low temperatures, for hours. An attacker can freeze RAM, transfer it to another machine, dump memory, and scan for AES key schedules with aeskeyfind. Demonstrated against BitLocker, FileVault, dm-crypt by Princeton in 2008.

Defense: disable hibernation, enforce TPM + anti-hammering PIN, enable AMD SME / Intel TME hardware memory encryption.
